 Bank Loan Analysis Dashboard

 Project Overview

The **Bank Loan Analysis Dashboard** is a data analysis project developed using **Microsoft Excel** and **Microsoft Power BI**. The project analyzes bank loan data to provide meaningful business insights through interactive dashboards and visualizations.

The dataset was downloaded from **Kaggle** and initially cleaned using **Microsoft Excel**. After preparing the data by removing duplicates, handling missing values, correcting formatting issues, and verifying data types, the cleaned dataset was imported into **Power BI** for analysis and dashboard creation.

This project demonstrates the complete data analysis workflow, from data preparation to interactive business intelligence reporting.

🎯 Project Goal

The main objectives of this project are to:

- Analyze overall bank loan performance.
- Monitor loan approval and rejection trends.
- Evaluate loan distribution across different customer groups.
- Identify loan default patterns.
- Create an interactive dashboard for business decision-making.
- Demonstrate practical skills in Excel, Power BI, and Data Analysis.

## 🧹 Data Cleaning & Preparation

Before building the dashboard, the dataset was cleaned using **Microsoft Excel**.

The following tasks were performed:

- Removed duplicate records.
- Handled missing and blank values.
- Corrected formatting inconsistencies.
- Verified data types.
- Renamed columns where necessary.
- Removed unnecessary data.
- Prepared the dataset for analysis in Power BI.

   📊 Dashboard Features

The Power BI dashboard includes:

- KPI Cards
  - Total Loans
  - Total Loan Amount
  - Average Loan Amount

- Interactive Charts
  - Loan Status Analysis
  - Loan Purpose Analysis
  - Gender-wise Loan Distribution
  - Employment-wise Loan Distribution
  - State-wise Loan Distribution
  - Default Status Analysis

- Interactive Filters & Slicers
  - Gender
  - Loan Status
  - Employment Type
  - Loan Purpose
  - State

 🔄 Project Workflow

1. Downloaded the dataset from **Kaggle**.
2. Imported the dataset into **Microsoft Excel**.
3. Cleaned and prepared the dataset.
4. Imported the cleaned Excel file into **Microsoft Power BI**.
5. Created data models and calculated measures.
6. Built interactive charts, KPIs, and slicers.
7. Designed a professional dashboard to analyze bank loan performance.
